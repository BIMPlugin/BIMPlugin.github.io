What is Check Circuit?

Check Circuit is a tool designed for reviewing, filtering, sorting, and editing electrical circuit parameters in Autodesk Revit.

It displays selected connected electrical devices in an interactive table, allowing users to review multiple circuits simultaneously and modify individual or multiple parameter values without opening each element separately.

The tool also includes four independent filters, column sorting, multi-selection editing, and visual highlighting of unsaved changes.

How to Use Check Circuit?

  1. Select Electrical Elements

    Select one or multiple connected electrical devices in your Revit model.

  2. Open Check Circuit

    Navigate to BIM Electrical → Circuit Tools → Check Circuit.

  3. Review Circuit Parameters

    The selected elements are displayed in a table containing:

    • Load Name
    • Number of Poles
    • Voltage Utilization
    • O_Apparent Load (VA)
    • O_Power Factor
    • Rating (A)
    • Circuit Project Parameter (for example, Circuits Size)
    • Load Classification
    • Electrical Panel

  4. Select Circuit Project Parameter

    Use the Circuit Project Parameter dropdown to select the project parameter displayed in the corresponding table column. The selected parameter is remembered for future use in the same project.

  5. Sort the Table

    Click a column header to sort the elements by that parameter. Only one sorting criterion is active at a time.

  6. Filter Electrical Elements

    Use Filter 1–4 on the right side of the window:

    • Select the parameter to filter.
    • Enter the required text in the Value field.
    • The table displays only elements containing the specified text.
    • Multiple active filters work together to narrow the results.

  7. Edit Parameter Values

    Click an editable cell and enter a new value or select an available option from its dropdown list.

    Number of Poles and Voltage Utilization are read-only and displayed in gray.

  8. Edit Multiple Elements Simultaneously

    Select multiple cells within the same parameter column:

    • Hold Ctrl to select individual cells.
    • Hold Shift to select a range of cells.
    • Enter a new value or select one from a dropdown list to update the selected cells.

  9. Review Modified Values

    Modified parameter values are highlighted in orange, making it easy to identify changes that have not yet been applied.

  10. Apply Changes

    Click Apply Changes to save the modified parameters to the Revit model. Successfully applied values return to black, and the window remains open for further checking and editing.

  11. Close the Window

    Click Cancel to close the window without applying any remaining unsaved changes.

Result

Users can efficiently review, filter, sort, and update electrical circuit parameters for multiple devices within a single interface.

Note: Changes to circuit-level parameters are reflected across selected rows belonging to the same circuit. Only successfully applied changes are saved to the Revit model.
