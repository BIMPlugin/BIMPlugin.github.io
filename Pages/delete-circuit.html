What is Delete Circuit?

Delete Circuit is a tool designed to quickly disconnect selected electrical devices from their existing power circuits in Autodesk Revit.

The tool allows users to remove electrical connections from multiple devices at once while preserving circuits that still contain other connected devices.

How to Use Delete Circuit?

  1. Select Electrical Elements

    Select one or multiple devices that are connected to electrical power circuits.

  2. Open Delete Circuit

    Navigate to BIM Electrical → Circuit Tools → Delete Circuit.

  3. Execute the Command

    The tool automatically identifies the electrical circuits associated with the selected devices.

  4. Disconnect Selected Devices

    The selected devices are removed from their associated circuits.

  5. Remove Empty Circuits

    If all devices belonging to a circuit are selected, the circuit is automatically deleted. If other devices remain connected, the circuit is preserved.

Result

The selected devices are disconnected from their electrical circuits. Empty circuits are removed automatically, while circuits containing unselected devices remain in the model.

Note: The command completes without displaying a confirmation window when no errors occur. An error message appears only if a problem is detected.
