What is Create Circuit?

Create Circuit is a tool designed to simplify and speed up the creation of electrical power circuits in Autodesk Revit.

It allows users to create individual circuits for multiple selected devices or connect them to a single circuit. Users can configure the connection type, voltage, electrical panel, and additional electrical parameters in one interface.

How to Use Create Circuit?

  1. Select Electrical Elements

    Select one or multiple electrical devices in your Revit model.

  2. Open Create Circuit

    Navigate to BIM Electrical → Circuit Tools → Create Circuit.

  3. Choose Circuit Mode

    Select one of the following options:

    • Separate Circuits: Creates an individual circuit for each selected device.
    • Single Circuit: Connects the selected devices to one circuit.

  4. Select Connection Type and Voltage

    Choose the required connection configuration:

    • 1 Phase, 1 Pole — 120 V or 277 V
    • 1 Phase, 2 Poles — 208 V or 480 V
    • 3 Phase, 3 Poles — 208 V or 480 V

  5. Select Electrical Panel

    Choose a compatible electrical panel from the available list. Panels are filtered based on the selected electrical configuration.

  6. Configure Additional Parameters

    Enter the required values for:

    • O_Apparent Load (VA)
    • O_Power Factor (0–1)
    • Load Classification
    • Load Name
    • Rating (A)
    • Circuit Project Parameter and Value

  7. Create Circuits

    Click Create Circuits to create the electrical connections and apply the specified parameters.

Result

Electrical circuits are created for the selected devices using the specified connection settings and parameters.
