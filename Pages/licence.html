What is Licence?

Licence is a security feature designed to protect BIM Plugin from unauthorized use by ensuring that only users with an active licence can access its tools and features.

The licensing system is based on a unique User ID assigned to each user. Access to BIM Plugin is granted individually by the developer, ensuring that the plugin can only be used by authorized users.

How to Use Licence?

  1. Click Licence in the BIM Plugin ribbon.
  2. A dialog window will appear displaying your unique User ID.
  3. Copy your User ID from the dialog window.
  4. Send your User ID to the BIM Plugin developer to request a licence.
  5. Once the developer activates your licence, you will be granted access to BIM Plugin and its features.
