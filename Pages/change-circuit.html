What is Change Circuit?

Change Circuit is a tool that allows users to modify the parameters of existing electrical circuits and their connected devices in Autodesk Revit.

It provides a convenient interface for updating electrical loads, circuit information, load classifications, and electrical panel assignments without manually editing each element in the Properties palette.

How to Use Change Circuit?

  1. Select Connected Electrical Elements

    Select one or multiple devices that are already connected to electrical power circuits.

  2. Open Change Circuit

    Navigate to BIM Electrical → Circuit Tools → Change Circuit.

  3. Review Existing Parameters

    The tool displays the current parameter values of the selected devices and circuits. If different values are detected, the corresponding field displays <varies>.

  4. Modify the Required Parameters

    Update any of the following:

    • Electrical Panel
    • O_Apparent Load (VA)
    • O_Power Factor (0–1)
    • Load Classification
    • Load Name
    • Rating (A)
    • Circuit Project Parameter and Value

  5. Leave Unchanged Parameters as They Are

    Only parameters that you modify will be updated. Other values remain unchanged.

  6. Apply Changes

    Click Change Circuit to apply the updated values to the selected devices and their associated circuits.

Result

The specified electrical parameters are updated without recreating the existing circuits.

Note: Circuit-level changes affect all devices connected to the same circuit. Electrical panel reassignment may be restricted when a circuit contains devices that were not selected.
