What is ID Link Element?

ID Link Element allows users to quickly retrieve the Element ID of any element from a linked Revit model.

This tool simplifies identifying elements in linked models by displaying their Element IDs without requiring users to open the linked Revit files.

How to Use ID Link Element?

  1. Click ID Link Element in the BIM Plugin ribbon.
  2. Select an element from a linked Revit model whose ID you want to retrieve.
  3. A dialog window will appear displaying the selected element's ID.
  4. Copy the Element ID from the dialog window for further use.
